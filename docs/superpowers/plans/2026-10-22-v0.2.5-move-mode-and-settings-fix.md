# SuperSwingTimer v0.2.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Interactive Move Mode (`/sst move`, `/sst unlock`, floating Move HUD), fix the 1080p settings panel clipping & Blizzard detachment bug via decoupled canvas architecture, and add native Titanforge / Anniversary cross-client aura support for v0.2.5.

**Architecture:**
1. Decouple Blizzard's `SettingsPanel` canvas from the standalone window by creating a dedicated `SuperSwingTimerBlizzardOptionsPanel` canvas, preventing Blizzard from orphaning the standalone panel on close/tab switch.
2. Responsively size and clamp the standalone `SuperSwingTimerConfigPanel` to 720x560 (dynamically adjusted to `UIParent:GetHeight() - 70`), adding resizability so all headers, controls, search bar, and reset buttons fit without clipping on 1080p (768 virtual height), ElvUI scaled views, and laptops.
3. Introduce an Interactive Move Mode (`/sst move`, `/sst unlock`, `/sst lock`) that displays labeled drag overlays on all bars and summons a floating `SuperSwingTimerMoveHUD` toolbar with a one-click `[ Lock Bars & Save ]` button.
4. Support Titanforge (3.80.2), TBC Anniversary (2.5.6), and Classic Era (1.15.9) in `SuperSwingTimer.toc` and normalize `C_UnitAuras.GetAuraDataByIndex` ahead of legacy `UnitAura`.

**Tech Stack:** World of Warcraft Classic API (Lua 5.1), Blizzard Settings API / InterfaceOptions, FrameXML, Headless Lua Test Runner.

## Global Constraints
- Target Version: `v0.2.5`
- Supported Client Interfaces: `11507, 11508, 11509, 20505, 20506, 38002, 30802`
- Must preserve right-click camera pass-through (`SetMouseClickEnabled("RightButton", false)`).
- All tests must pass in `lua run_tests.lua` with 0 failures.
- `luacheck` must pass with 0 errors / 0 warnings on all touched Lua files.

function ns.UnitAura(unit, index, filter)
    if not unit or not index then return nil end

    -- Primary: Check modern / Titanforge C_UnitAuras API
    local cUnitAuras = rawget(_G, "C_UnitAuras")
    if cUnitAuras and cUnitAuras.GetAuraDataByIndex then
        local aura = cUnitAuras.GetAuraDataByIndex(unit, index, filter)
        if aura then
            return aura.name, nil, aura.icon, tonumber(aura.applications) or 0, aura.dispelName,
                   aura.duration, aura.expirationTime, aura.sourceUnit,
                   aura.isStealable, nil, aura.spellId
        end
        return nil
    end

    -- Fallback: Legacy UnitAura global
    if not UnitAura then return nil end
    local r1, r2, r3, r4, r5, r6, r7, r8, r9, r10, r11 = UnitAura(unit, index, filter)
    if not r1 then return nil end

    if type(r3) == "string" then
        return r1, r2, r3, tonumber(r4) or 0, r5, r6, r7, r8, r9, r10,
               type(r11) == "number" and r11 or type(r10) == "number" and r10 or nil
    elseif type(r3) == "number" and (type(r10) == "number" or type(r9) == "boolean") then
        return r1, nil, r2, tonumber(r3) or 0, r4, r5, r6, r7, r8, nil,
               type(r10) == "number" and r10 or nil
    else
        return r1, nil, nil, tonumber(r3) or 0, r4, r5, r6, r7, r8, nil,
               type(r9) == "number" and r9 or nil
    end
end
```

SlashCmdList["SUPERSWINGTIMER"] = function (msg)
    msg = strtrim(msg or ""):lower()
    if msg == "reset" then
        local ok, err = pcall(ns.ResetConfigDefaults)
        if ok then
            print("|cff00ccffSuper Swing Timer:|r Settings reset to defaults.")
        else
            print("|cff00ccffSuper Swing Timer:|r Could not reset settings: " .. tostring(err))
        end
    elseif msg == "move" or msg == "unlock" then
        if ns.StartMoveMode then
            ns.StartMoveMode()
        end
    elseif msg == "lock" then
        if ns.StopMoveMode then
            ns.StopMoveMode()
        end
    elseif msg == "test" then
        if ns.barTestActive then
            ns.HideBarPreview()
        else
            ns.ShowBarPreview()
        end
    elseif msg == "help" then
        print("|cff00ccffSuper Swing Timer (/sst):|r")
        print("  |cff00ff00/sst|r - Open/close settings panel")
        print("  |cff00ff00/sst move|r or |cff00ff00/sst unlock|r - Unlock bars and show drag anchors")
        print("  |cff00ff00/sst lock|r - Lock bars in current position")
        print("  |cff00ff00/sst test|r - Toggle test bars preview")
        print("  |cff00ff00/sst reset|r - Restore all default settings")
    else
        local ok, err = pcall(ns.ToggleConfig)
        if not ok then
            print("|cff00ccffSuper Swing Timer:|r Could not open config: " .. tostring(err))
        end
    end
end
```
