# Design Specification: SuperSwingTimer v0.2.6
**Topic:** Interactive Move Mode, 1080p Settings Panel Decoupling, and Titanforge Cross-Client Support  
**Date:** 2026-10-22  
**Target Version:** v0.2.6  
**Status:** Approved  

---

## 1. Overview & Problem Statement

Users of SuperSwingTimer reported two critical issues on CurseForge:
1. **"How do I MOVE the thing?"**:
   - Out of combat, bars are hidden by default. When bars are not shown, mouse events are disabled.
   - There was no `/sst move` or `/sst unlock` slash command.
   - There was no visual drag overlay or clear indicator indicating how to position bars, and `/sst help` omitted movement instructions.
2. **"Settings completely broken so I can't change anything / made for higher resolution than 1920x1080"**:
   - The standalone configuration window (`SuperSwingTimerConfigPanel`) was directly registered as a canvas in Blizzard's Settings (`Settings.RegisterCanvasLayoutCategory(panel)`).
   - Whenever a player closed or switched categories in Blizzard's SettingsPanel (or InterfaceOptionsFrame), Blizzard called `panel:SetParent(nil)` and `panel:ClearAllPoints()`. This permanently orphaned the panel, causing `/sst` to fail or render an unresponsive, unanchored frame.
   - Standalone dimensions were hardcoded to `780x760` with `SetClampedToScreen(true)`. On standard 1920x1080 screens (where WoW defaults to a 768 virtual height) or with ElvUI / high UI scale (600–720 height), 760px exceeds the screen viewport, pushing the title bar, close button, search bar, and bottom action buttons off-screen.
   - When displayed inside Blizzard's ~623px settings canvas, the 720px content child clipped off-screen, cutting off color pickers and right-column controls.
3. **Cross-Client Requirement**:
   - Support across `classic_era` (1.15.x), `classic_anniversary` (TBC 2.5.6), and `titanforge` (`classic_titan` 3.80.2 from `/home/sam/wow-ui-source`).
   - In Titanforge (3.80.2), legacy `UnitAura` is deprecated under `loadDeprecationFallbacks`. Direct support for `C_UnitAuras.GetAuraDataByIndex` is required.

## 2. Interactive Move & Unlock Mode

### 2.1 Slash Commands
- `/sst move` and `/sst unlock`:
  - Enters **Move Mode**.
  - Sets `SuperSwingTimerDB.lockBars = false`.
  - Displays visible preview bars with semi-transparent drag anchor boxes and distinct labels:
    - `"Main Hand (Drag to Move)"`
    - `"Off Hand"` (follows Main Hand automatically)
    - `"Ranged / Auto Shot (Drag to Move)"`
    - `"Enemy Swing (Drag to Move)"`
  - Spawns the floating `SuperSwingTimerMoveHUD` toolbar.
  - Prints instructions to chat: `|cff00ccffSuper Swing Timer:|r Bars unlocked. Left-click and drag bars to reposition. Type |cff00ff00/sst lock|r or click [Lock Bars] when finished.`
- `/sst lock`:
  - Exits Move Mode.
  - Sets `SuperSwingTimerDB.lockBars = true`.
  - Hides test/preview bars and drag overlays.
  - Hides `SuperSwingTimerMoveHUD`.
  - Calls `ns.ApplyLockBars()` to disable bar mouse capture (preserving right-click camera movement).
  - Prints confirmation: `|cff00ccffSuper Swing Timer:|r Bars locked in position.`
- `/sst help`:
  - Updated to document `/sst`, `/sst move`, `/sst unlock`, `/sst lock`, `/sst reset`, `/sst help`.

### 2.2 Floating Move HUD (`SuperSwingTimerMoveHUD`)
- Lightweight movable frame anchored near top-center (`UIParent`).
- Contains:
  - Header: `"Super Swing Timer: Repositioning Mode"`
  - Description: `"Left-click and drag any active bar to move."`
  - Action Button: `[ Lock Bars & Save ]` (clicking calls the lock routine).
  - Close button (`X`) or `Esc` key support to lock and close.

## 3. Settings Panel Architecture & 1080p Resolution Fix

### 3.1 Decoupled Blizzard Settings Canvas
- Register a dedicated, clean Blizzard AddOns canvas frame (`SuperSwingTimerBlizzardOptionsPanel`):
  - Used for `Settings.RegisterCanvasLayoutCategory(blizzardPanel, "Super Swing Timer")` / `InterfaceOptions_AddCategory(blizzardPanel)`.
  - Borderless, standard Blizzard design (no standalone dialog backdrop or external close button).
  - Contains:
    - Header: `"Super Swing Timer v0.2.6"`
    - Descriptive text on core features and slash commands.
    - Buttons:
      - `[ Open Full Settings Panel (/sst) ]` → invokes `ns.ToggleConfig()`.
      - `[ Unlock & Move Bars (/sst unlock) ]` → initiates Move Mode.
      - `[ Reset All Defaults (/sst reset) ]` → resets defaults with confirmation.
    - Embedded quick toggle checkbuttons:
      - `Lock Bars`
      - `Minimal Mode`
      - `Enable Melee Swing Timer`
      - `Enable Ranged Swing Timer`
      - `Enable Enemy Swing Timer`
- Blizzard's `SettingsPanel` only manages this canvas frame. Blizzard never parents, clears points, or hides the standalone config window.

### 3.2 Standalone Config Window (`SuperSwingTimerConfigPanel`)
- Permanently parented to `UIParent`, frame strata `DIALOG`, clamped to screen.
- Responsive Dimensions:
  - Default width: `720` (fits within 1024+ screen width).
  - Default height: dynamically clamped on `OnShow`:
    `local screenH = UIParent:GetHeight() or 768`
    `local targetH = math.min(580, math.max(420, screenH - 70))`
    `f:SetSize(720, targetH)`
  - Frame resizability enabled (`f:SetResizable(true)`) with corner resize grip (min bounds: `640x400`, max bounds: screen dimensions).
- Fixed Layout Anchors:
  - Header: Title and Close button at `TOP` and `TOPRIGHT`.
  - ScrollFrame: Anchored `TOPLEFT (14, -46)` to `BOTTOMRIGHT (-26, 48)`.
  - Bottom controls:
    - `searchBox`: Anchored `BOTTOMLEFT (14, 16)` to `BOTTOMRIGHT (-140, 16)` with height 22.
    - `resetBtn`: Anchored `BOTTOMRIGHT (-16, 14)` with size `116x22`.
  - Guarantees 100% on-screen visibility of all headers, controls, search, and reset buttons on 1080p (768 virtual height), ElvUI custom scales, and laptops.
- Recovery Mechanism:
  - Inside `ns.ToggleConfig()`, verify `f:GetParent() == UIParent` and `f:GetNumPoints() > 0`. If missing or detached, immediately re-parent to `UIParent` and `f:SetPoint("CENTER")`.

## 4. Cross-Client Compatibility (Classic Era, Anniversary, Titanforge)

### 4.1 TOC File Updates (`SuperSwingTimer.toc`)
- Version: `v0.2.6`
- Supported interfaces:
  ```toc
  ## Interface: 11509, 20506, 38002
  ## Interface-Classic: 11509
  ## Interface-BCC: 20506
  ## Interface-Titan: 38002
  ## Version: v0.2.6
  ```

### 4.2 Native `C_UnitAuras` Normalization
- In `SuperSwingTimer_Constants.lua` (`ns.UnitAura`):
  - Check for `C_UnitAuras and C_UnitAuras.GetAuraDataByIndex` first.
  - If present, retrieve the aura table and unpack canonical 11-value tuple:
    `aura.name, nil, aura.icon, aura.applications, aura.dispelName, aura.duration, aura.expirationTime, aura.sourceUnit, aura.isStealable, nil, aura.spellId`
  - If nil or not present, fall back to legacy multi-return `UnitAura` unpacking (Shape A, B, C, D).
  - Guarantees aura tracking continues functioning seamlessly when clients disable `loadDeprecationFallbacks`.
