# Development & Quality Standards

## 1. Zero-Tolerance Linter Policy

- Addon codebase must pass `luacheck .` with **0 warnings and 0 errors** across all 11 Lua files at all times.
- Avoid shadowing upvalues (e.g. using `fs` or descriptive parameter names instead of `self` inside callbacks).
- Do not leave unused local variables or assignments.

## 2. Localization & Font Safety

- **Never** hardcode Western font paths (`"Fonts\\FRIZQT__.TTF"`) or double backslashes (`Fonts\\\\...`).
- Always resolve fonts through `ns.GetDefaultFont()` or `GetFontPath()`, which queries Blizzard's `rawget(_G, "STANDARD_TEXT_FONT")` first.
- This ensures full compatibility with Cyrillic (`ruRU`), Korean (`koKR`), and Simplified/Traditional Chinese (`zhCN`, `zhTW`) clients.

## 3. Frame & Glow Border Construction

- Never use positional array iteration over edge coordinate tuples for glow borders.
- Always construct explicit named textures (`top`, `bottom`, `left`, `right`) with direct numeric coordinate offsets (`SetPoint("TOPLEFT", -1, 1)` etc.) to prevent passing dimension keys like `"Height"` into `SetPoint()`.

## 4. UI Alignment Standards

- **Debuff Icons**: Anchored strictly to the outside left (`RIGHT`, `bar`, `LEFT`, -2, 0) with `SetTexCoord(0.07, 0.93, 0.07, 0.93)`. Debuff bars remain aligned at $X=0$.
- **Buff Icons**: Timer text centered above the icon (`"BOTTOM", icon, "TOP", 0, 2`). Stack text on the icon face (`"BOTTOMRIGHT"`).
- **Power Bar**: Unified height of 10px across all classes.
- **Hunter Cast Bar**: 15px default height.

## 5. Dual-Client Support

- All API calls must gracefully handle both Modern Classic APIs (`C_Spell`, `C_UnitAuras`, `IsSpellKnownOrOverridesKnown`) and Classic Era / TBC Anniversary fallback globals (`GetSpellInfo`, `UnitBuff`, `UnitDebuff`, `IsPlayerSpell`).

## 6. Blizzard API Research via wow-ui-source

To verify Blizzard FrameXML behaviors, API signatures, return types, and client branch variations:

- **Repository**: [wow-ui-source](https://github.com/Gethe/wow-ui-source) (community mirror of Blizzard's exported interface code).
- **Target Branches**:
  - `classic_era`: For Classic Era / Season of Discovery (`1.15.x`).
  - `classic` / `bcc`: For Burning Crusade Classic / TBC Anniversary (`2.5.6`).
  - `live`: For modern retail baseline comparison.
- **Key Directories to Check**:
  - `Interface/FrameXML/`: Core frame implementations (e.g. `Constants.lua`, `UIParent.lua`, `UnitPower.lua`, `PowerBarColor` tables, combat log handlers).
  - `Interface/SharedXML/`: Cross-branch shared libraries (`C_Spell`, `C_UnitAuras`, math utilities, animation templates).
  - `Interface/AddOns/Blizzard_APIDocumentationGenerated/`: Autogenerated Blizzard API documentation specifying exact argument types, return signatures, and event payloads.
  - `Interface/FrameXML/GlobalStrings.lua`: Blizzard global strings, localization tokens, and format strings.
- **Common Research Workflows**:
  - **Return Types**: Verify whether an API returns a table or tuple (e.g., confirming `GetPowerBarColor` returns `{ r, g, b }` table in Classic FrameXML).
  - **Event Signatures**: Check event payload changes across patches (e.g., `UNIT_SPELLCAST_START` payload differences: `unit, castGUID, spellID` vs older Classic `unit, spellName`).
  - **Global Variables**: Check existence of globals (e.g., `STANDARD_TEXT_FONT`, `PowerBarColor`, `RAID_CLASS_COLORS`).
